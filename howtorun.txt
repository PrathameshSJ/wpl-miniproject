HOW TO RUN:

Option 1 (One-click launch both frontend and backend):
   npm run dev

Option 2 (Run services independently):
   Terminal 1 (Backend - Express & MongoDB):
      cd server
      npm run dev
      -> Running on http://localhost:5000

   Terminal 2 (Frontend - React & Vite):
      cd client
      npm run dev
      -> Running on http://localhost:5173

DATABASE:
   - Zero-Config: If no MongoDB is active, an embedded in-memory MongoDB automatically starts and seeds all data out-of-the-box!
   - External MongoDB: Set MONGODB_URI in server/.env (e.g., local MongoDB or MongoDB Atlas connection string).
